# Architecture

## Vision

AI Sales Toolkit is designed as a modular collection of reusable components for AI-powered business applications.

Instead of a single monolithic system, the project is organized into independent modules that can be used separately.

## Planned Modules

### CRM

- Lead management
- Opportunity tracking
- Sales pipeline

### Pricing

- Margin calculator
- Markup calculator
- Discount simulator

### Dashboards

- Sales KPIs
- Store performance
- Salesperson performance

### Automation

- Workflow templates
- AI prompts
- Report generation

### Analytics

- Commercial indicators
- Pricing analysis
- Sales forecasting
